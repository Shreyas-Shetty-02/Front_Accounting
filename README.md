# Front_Accounting

# 🧪 FrontAccounting – Software Testing Project

A practical **Manual Software Testing / QA project** performed on **FrontAccounting v2.4.15**, a web-based ERP and accounting application.

The main objective of this project was to understand the application, design test scenarios and test cases, execute them, identify defects, and document the results with proper test evidence.

---

## 📊 Project Overview

| Testing Metric | Result |
|---|---:|
| Test Scenarios | 42 |
| Test Cases | 132 |
| Passed | 110 |
| Failed | 24 |
| Defects Reported | 24 |

---

## 🔍 Modules Tested

### 🛒 Sales
- Sales Quotation
- Sales Order
- Delivery
- Invoice
- Customer Payment
- Quantity, Price & Discount Validation

### 📦 Purchase
- Purchase Order
- Receiving Purchase Orders
- Supplier Invoice
- Supplier Payment
- Quantity & Price Validation

### 🏭 Inventory
- Inventory Location Transfer
- Inventory Item Movements
- Inventory Item Status
- Positive, Negative & Zero Quantity Testing

## 🛠️ Testing Activities

The following testing activities were performed:

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Analysis
- Input Validation Testing
- Test Case Design
- Test Execution
- Defect Identification
- Defect Reporting
- Regression Testing Considerations

---

## 🐞 Defect Reporting

Defects were identified by comparing the **Expected Result** with the **Actual Result** during test execution.

Each defect was documented with relevant information such as:

- Defect ID
- Module / Sub-module
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity / Priority
- Status
- Screenshot Evidence
